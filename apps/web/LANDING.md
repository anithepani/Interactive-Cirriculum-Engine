# ICE Landing Page

Premium marketing landing at `/` — 12 section components + Navbar/Footer.

## Structure

```
src/components/sections/
  Hero.tsx
  InstructorSpotlight.tsx
  LogoMarquee.tsx
  ValuePropositionFan.tsx
  VisionSplitGrid.tsx
  LearnerMatrix.tsx
  FeatureMosaic.tsx
  MarketplaceCarousel.tsx
  ComponentGridMatrix.tsx
  PricingNodes.tsx
  NeonMarqueeBelt.tsx
  DualCTABlocks.tsx
src/lib/data.ts    — all copy/constants (PRODUCT, NAV_LINKS, etc.)
src/lib/motion.ts  — shared Framer Motion variants
```

## Design tokens

CSS custom properties in `globals.css` (`--bg-canvas`, `--accent-lime`, etc.).
